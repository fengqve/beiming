# Beiming · 北冥神功

**看懂材料，找到与你有关的启发。**

一个轻量的 Codex Skill：分析你发来的图片、链接和文字，理解其结构与内核，
再结合你的意图，判断有什么值得借鉴和保留。

[English](README.md) · [试读示例](examples/input.md) · [查看核心指令](skills/beiming/SKILL.md)

你发来一个有意思的东西，Beiming 帮你回答：**它真正值得注意的是什么？其中哪些对你有用？**
先理解材料，再谈关联；没有新增借鉴价值，也可以直接说没有。

## 一个小例子

**你：**“我已经给写作资料打标签，但过几周就忘了当初为什么收藏。不想再增加分类负担。”
你分享了一个带有三种阅读分栏、可选收藏理由的应用构想。

**Beiming 的实际回答，节选译文：**

> 最值得借鉴的，是保留为什么收藏，而不是增加更多分类。

> 你可以借用分栏背后的问题——“我为什么可能再来看它？”——而不用照搬这些分栏或换一个应用。

回答还区分了未经验证的设计设想和实际效果证据。
[查看输入](examples/input.md)与[完整英文回答](examples/output.md)。
输入是本项目原创的虚构素材；回答来自实际运行，不代表已验证的产品成效。

## 开始使用

在 Codex 中请内置安装器安装：

```text
$skill-installer install https://github.com/fengqve/beiming/tree/v0.1.0/skills/beiming
```

然后附上图片、粘贴文字或提供链接：

```text
$beiming 这个有什么值得借鉴的？我正在考虑……，但不希望……。
```

背景不是必填项。在已有相关背景的对话中直接调用即可；没有背景时，也能分析材料，
但不应假装了解你。有技能选择器的客户端也可以选择 **Beiming · 北冥神功**。
安装后若未显示，先在新任务中检查技能列表及客户端设置。
客户端差异见 [Codex 官方技能文档](https://learn.chatgpt.com/zh-Hans/docs/build-skills)。

## 它会帮你分清什么

- **启发**：这份材料让你看见了什么此前忽略的东西？
- **借鉴**：哪个具体机制适合你，迁移时要改什么，什么不能照搬？
- **沉淀**：哪些认识值得以后复用，又在什么条件下成立？

这不是每次必须填满的三个栏目。篇幅和形式随材料而变；泛泛总结、漂亮比喻，
或“注重体验、持续学习”一类万能建议，不等于真正的借鉴。

## 为什么是北冥神功，而不是吸星大法？

名字借自金庸武侠中的 **北冥神功**。**吸星大法**给了我们一个很好的提醒：
吸收外来的内力，也可能因异种力量积聚、难以调和而带来副作用。

学习也一样。别人有效的方法，连同未经理解的前提一起搬进来，可能增加负担，
甚至与自己已有的做法互相冲突。**吸收，不等于消化；收集，不等于会用。**

我们用“北冥”寄托的是 **理解、取舍、融会**：看懂它为什么有效，辨认适用条件，
再把适合的部分转化为自己的认识。在这个 Skill 里，“融会”首先是一份有根据的建议，
不是擅自替你修改项目或写入记忆。

这是本项目的命名寓意，不是对小说不同版本武学设定的严格考据。
项目独立开发，与金庸作品权利方无官方关联；不熟悉武侠，也不影响使用。

## 刻意保持简单

运行包只有两个文件，不捆绑后台、爬虫、数据库、API 密钥或遥测代码。
读取和分析依赖当前 Codex 会话已有的模型与工具。

- 不保证所有链接都能打开，也不能读取你的全部历史聊天。
- 看不清的图片、读不到的正文，应说明限制，不凭空补齐。
- “值得沉淀”只是候选认识，不自动保存记忆、改规则或改项目。
- 数据处理仍遵循宿主平台规则，不承诺纯离线或绝不上传。
- 未声明其他 Agent 或插件市场安装已通过验证。
